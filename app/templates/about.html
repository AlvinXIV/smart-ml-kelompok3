Project Overview

AI Predictive Maintenance

AI Predictive Maintenance adalah aplikasi machine learning yang mendemonstrasikan bagaimana beberapa paradigma AI dapat dikombinasikan untuk mendukung predictive maintenance. Sistem memanfaatkan parameter operasi mesin untuk memperkirakan risiko kegagalan, memahami kondisi operasi, dan menghasilkan rekomendasi tindakan pemeliharaan.

Predictive MaintenanceMachine LearningIndustrial Analytics
SYSTEM PURPOSE
Predict before failure
Monitoring · Analysis · Decision Support
Satu workspace untuk melihat kondisi mesin dan hasil analisis secara lebih terstruktur.

Machine Learning Framework

Tiga pendekatan machine learning bekerja sebagai bagian dari satu alur analisis.

SUPERVISEDRandom Forest

Failure Prediction

What is the failure risk?

Model klasifikasi memprediksi apakah mesin berpotensi mengalami kegagalan berdasarkan operating parameters seperti temperature, rotational speed, torque, dan tool wear.

OutputFailure Probability
UNSUPERVISEDK-Means

Condition Clustering

What condition is it in?

Clustering digunakan untuk mengelompokkan mesin dengan karakteristik operasi yang serupa sehingga pola kondisi mesin dapat dipahami.

OutputMachine Condition Cluster
REINFORCEMENTQ-Learning

Maintenance Decision

What action should be considered?

Q-Learning digunakan untuk memilih tindakan maintenance berdasarkan kondisi mesin dan reward yang dipelajari.

ActionsContinue · Inspect · Maintenance

Failure Mode Taxonomy

Tool Wear Failure

Kegagalan yang berkaitan dengan keausan tool.

Tool wear
HDF

Heat Dissipation

Kondisi kegagalan yang berkaitan dengan disipasi panas.

Thermal condition
PWF

Power Failure

Kondisi kegagalan yang berkaitan dengan daya mekanis.

Power / torque

Load condition

End-to-End System Pipeline

Alur dari machine parameters sampai hasil analisis dan rekomendasi.

1

Machine Parameters

Temperature, rotational speed, torque, tool wear, dan parameter operasi lainnya masuk ke sistem.

2

Preprocessing

Data dipersiapkan agar dapat digunakan oleh model machine learning.

3

Tri-ML Analysis

Random Forest, K-Means, dan Q-Learning menjalankan perannya masing-masing.

4

Final Analysis

Hasil analisis disajikan sebagai failure risk, cluster, dan maintenance action.
